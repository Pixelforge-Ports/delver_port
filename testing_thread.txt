Delver testing build
Porter: Pixelforge ports (Ronax)
Game: https://store.steampowered.com/app/249630/Delver/

Install Delver.zip through PortMaster's autoinstall folder. Copy your owned delver.jar to ports/delver/delver.jar.
Requires Delver v1.08 from Steam depot 249631, manifest 6680730644186394716.
Steam console command: download_depot 249630 249631 6680730644186394716
Follow delver.md for the checksum and installation instructions. No game files are included.

The port uses gptokeyb2 keyboard and mouse emulation through `delver/delver.ini`. Direct gamepad input is disabled so physical joystick axes cannot also trigger attacks or drops. Use the right stick to point at a menu item and R2 to click; Start goes back. Two analog sticks are recommended for simultaneous movement and looking. Button labels follow the firmware's PortMaster controller mapping.

| Button | Action |
| --- | --- |
| Left stick / D-pad | Move forward/backward and strafe (WASD) |
| Right stick | Look / move menu cursor |
| A | Use / interact (E) |
| B | Jump (Space) |
| X | Inventory (I) |
| Y | Map (M) |
| L1 / R1 | Previous / next item |
| L2 | Drop item (Q) |
| R2 | Attack / click menu or inventory item (left mouse) |
| R3 (hold) | Slower mouse movement |
| Start | Pause / options / back (Escape) |
| Select (hold) + A | Enter / confirm |
| Select (hold) + B | Escape / back |
| Select (hold) + D-pad | Arrow keys |
| Select + Start | PortMaster exit shortcut |

Please verify: right-stick movement never attacks or drops an item; repeated R2 attacks do not drop it; L2 drops; B jumps while grounded; right-stick cursor movement and R2 clicks work in menus and inventory. Also check that the complete options menus fit the display. Test with existing saves as well as fresh settings. The startup log should report input=gptokeyb2 keyboard/mouse and native controllers=0. Control debug output is disabled; error logging remains enabled. Verify the software cursor, menu clicks, inventory dragging and continuous turning past the screen edges. The tester reports all controls working; further device and firmware testing is welcome.
